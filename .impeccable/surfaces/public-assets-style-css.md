# Surface brief: whole site (public pages + staff admin), shared stylesheet

Scope: every page styled by `public/assets/style.css`. Mode: Operate. Youths register on phones from LINE/IG links; staff run activities, check-in, surveys, venue bookings and monthly reports. Copy and the logo banner stay; only the visual layer changes. The user asked for a site that no longer looks templated and whose colours have energy.

## Direction contract

THESIS: The centre is Pilot.Cafe and its mark is a small aeroplane, so the site borrows the airport's own information design: activities read as a departures board, an activity's facts as a boarding pass. It refuses the pale-green stack of rounded white cards and pill badges.

OWN-WORLD: White terminal ground, deep night-navy boards, cobalt shell band, runway-amber for the one primary action and for board numerals. Status colours do gate-board jobs: green open, amber last days, sky-blue standby (候補), red full, grey closed. Squared 5–8px corners, hairline rules, no soft shadows. Latin and digits in B612 (the cockpit-display face), CJK in the system stack.

STORY: A youth lands, sees what is "departing" soon and whether it is still open, taps one, reads date/time/place on the pass, signs up. Staff find the same board logic in tables and counters.

FIRST VIEWPORT: White header with the logo banner and underlined text navigation; a full-width cobalt band carrying the page title and intro; the amber "查詢我的報名" strip; squared tabs (selected = navy); then the navy departures board, each row: amber day numeral, title, place, status cell at the right.
