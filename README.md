# 少年培力園 活動報名系統

給少年培力園用的活動報名網站。少年在前台報名，工作人員在後台管理活動與名單。

**核心特色：報名過一次就不用再填第二次。** 之後報名任何活動，只要輸入
**姓名 + 身分證字號 + 出生年月日**，系統就會自動帶出上次填過的所有資料，
按一下就完成報名。

---

## 快速開始

需要 Node.js 20 以上，以及一個 Postgres 資料庫。

```bash
npm install
DATABASE_URL='postgres://使用者:密碼@主機:5432/資料庫' node server.js
```

第一次啟動會自動建好資料表，並放一個範例活動讓你試用。

然後打開瀏覽器：

| 頁面 | 網址 | 誰可以看 |
| --- | --- | --- |
| 活動列表（報名首頁） | <http://localhost:3000/> | 所有人 |
| 過往活動 | <http://localhost:3000/past> | 所有人 |
| 單一活動報名頁 | `/activity/<活動代稱>` | 所有人 |
| 工作人員後台 | <http://localhost:3000/admin> | 需要密碼 |

**後台密碼：`81599196`**（全形半形都可以輸入）

換 port：`PORT=8080 node server.js`

### 部署到 Vercel

1. 到 [vercel.com](https://vercel.com) 用 GitHub 帳號登入，選 **Add New → Project**，
   匯入這個 repo，其他設定都不用改，直接 Deploy。
2. 開一個資料庫：在 Vercel 專案的 **Storage** 分頁選 **Neon（Postgres）**，
   免費方案就夠用。建立後 Vercel 會自動把 `DATABASE_URL` 加進環境變數。
3. 到 **Settings → Environment Variables** 再加兩個（很重要，見下方「上線與安全」）：

   | 名稱 | 值 |
   | --- | --- |
   | `ADMIN_PASSWORD` | 你要用的後台密碼 |
   | `SESSION_SECRET` | 一串長亂碼，例如 `openssl rand -hex 32` 產生的 |

4. 回到 **Deployments** 按 **Redeploy**，讓新的環境變數生效。

網址會長得像 `https://你的專案名.vercel.app`，HTTPS 是自動的。

## 前台：少年怎麼報名

進到活動頁之後有兩條路：

**1. 報名過培力園活動的老朋友**
輸入姓名、身分證字號、出生年月日 → 系統帶出完整資料 → 只要回答這次活動的
三個問題（從哪裡得知、報名原因、全程參與承諾）就送出。資料有變動（換學校、
升年級、換手機）可以按「資料有變動，我要修改」當場改，改完會同步更新後台主檔。

**2. 第一次報名**
填完整報名表（少年基本資料 + 監護人保險資料 + 活動問題）。送出後資料就存進
後台，下次報名就走第 1 條路。

系統會自動擋掉：重複報名同一個活動、額滿、過了報名截止日、活動已結束。

## 後台：工作人員怎麼用

### 活動管理（`/admin`）

- **新增活動**：填活動名稱與日期就能建立，其他欄位可留白。
  建立後會給一個報名網址，用「複製連結」按鈕就能貼到 LINE 分享。
- **每個活動一個子頁面**：點活動名稱進入該活動的報名名單。
- **過期自動歸檔**：活動日期一過，隔天就自動從「即將舉行」移到「過往活動」，
  不用手動搬。前台也會同步移到過往活動頁。
- **暫停報名**：編輯活動時取消勾選「開放報名」，活動還看得到但無法送出。
- **活動分類**（只有工作人員看得到，前台不顯示）：
  - 方案分類：社區與親子培力方案／微創實驗方案
  - 服務類型：團體工作／方案服務／社區工作
  - 細分類：自由填寫（例如「親子共學」），月報可以用它篩選，
    同一類的活動請填一樣的名稱才統計得在一起。
- **刪除活動**：需要輸入「刪除」兩個字確認。會連同該活動的報名紀錄一起刪除，
  但**學生的基本資料會保留**在學生資料總集裡。

### 單一活動名單（`/admin/activity/<id>`）

- 看這個活動的完整報名名單，可以用姓名、身分證、學校、電話、監護人搜尋。
- 點姓名展開這個人的完整報名內容，可以加工作人員備註（例：素食、需要接送）。
- **刪除某人的報名**：需要輸入該少年的姓名確認，避免手滑。
  刪掉的只是這一筆報名，他的基本資料還在。
- **下載這個活動的報名資料（CSV）**：欄位順序跟 Google 表單匯出一致，
  用 Excel 打開中文不會變亂碼。
- 「列印名單」可以直接印出當天要帶的紙本名冊。

### 連續性課程與簽到

活動可以是**單日**（例如淨灘），也可以是**連續性課程**（例如水電課 7-8 月每週三）。
兩者用同一套結構：一個活動底下有 1 到 N 個「場次」。

**建立多天活動**：新增活動時展開「這個活動不只一天？」，填最後一天，
再選上課方式：

- **連續每一天** —— 三天兩夜營隊、連續兩天的工作坊。
  例：12/1 到 12/3 ＝ 3 場。
- **每週固定星期** —— 勾選星期（可複選）。
  例：7/1 到 8/31 的每週三 ＝ 9 堂。

活動的起訖日期會自動跟著第一場與最後一場走。

> 連續性課程的「已結束」是看**最後一堂**，所以 7 月開課、8 月才結束的課程，
> 課還在上的期間不會被歸到過往活動。

**簽到**：少年掃 QR → 選課程 → 填姓名與身分證字號 → 完成。

- 簽到頁在 `/checkin`，只列出**今天**有課的場次。
- QR 可以帶場次代號（`/checkin?session=xxx`），掃進去就預選好那一堂，
  少年只要填名字。到後台的活動頁 →「簽到與出席」→ 任一場次的「QR」
  就能顯示並列印。
- 簽到只要姓名 + 身分證字號兩項（比報名少一項生日），現場隊伍才不會卡住。
- **沒報名的人也能簽到** —— 現場常有臨時來的少年，這些人算進出席人次，
  但會標記成「未報名」讓工作人員知道。
- 同一個人同一場只能簽到一次，由資料庫把關。
- 沒帶手機的少年，工作人員可以在後台代簽。

**出席總覽**：後台活動頁的「簽到與出席」分頁，會顯示報名者 × 各場次的
勾勾表，一眼看出誰全勤、誰缺席，以及每場的簽到人數。

### 月報統計（`/admin/reports`）

每個月要交給政府的數字。三張分佈表：**居住地區人次、年齡人次、身分別人次**，
另外附上活動場次、服務人次與實際人數（去重）。

- **可以回看任何一個月**，月份下拉選單會列出所有有資料的月份。
  預設顯示上個月，因為月報通常是月初交前一個月的數字。
- **統計基準可以切換**：
  - **依出席月份（預設）** ＝ 每一次簽到算一人次。連續性課程來了 6 堂就算
    6 人次，這是實際的服務量，也是政府要的數字。
  - 依活動舉辦月份 ＝ 本月辦了哪些活動、有多少人報名。
  - 依報名月份 ＝ 本月有多少人送出報名。
  三種算出來的數字不一樣，看政府要哪一種。
- 用出席基準時，年齡是按**上課那天**算的（連續性課程橫跨生日也準），
  而且現場臨時參加、沒有報名紀錄的人也算得進去。
- **可以依活動分類篩選**（方案分類／服務類型／細分類），
  三張分佈表會跟著只算該分類的活動。
- 有活動還沒分類時會跳出提醒，避免月報少算。
- 可以下載 CSV 或直接列印。

### 學生資料總集（`/admin/students`）

所有報名過的少年都在這裡，一個人一筆，不會因為報名多次而重複。

- **搜尋**：姓名、身分證字號、學校、居住區域、手機、住家電話、LINE ID、
  Email、監護人姓名與電話、生日（西元或民國）都搜得到。
- 點姓名看完整資料 + **他報名過哪些活動**。
- 可以直接編輯資料（例如升學換學校），改完之後的活動都會用新資料。
- 刪除學生會連同他所有報名紀錄一起刪除，需要輸入姓名確認。
- 可以下載全部學生資料，或只下載目前搜尋結果。

## 收集哪些資料

欄位完全照著培力園原本的 Google 報名表單設定，定義都在
[`src/fields.js`](src/fields.js)，要增減欄位改那一個檔案就好，
前台表單、後台表格、CSV 匯出會一起跟著變。

**存進學生主檔（只填一次）**

少年姓名、身份證字號、出生年月日、性別、身分別、特殊家庭狀況、就讀學校、
年級、學籍/居住區域（限新北市 29 區）、居住地址、住家電話、少年手機、
LINE ID、Email、監護人姓名／身分證號／出生年月日／國籍／與學生關係／聯絡電話。

**每次報名都要填**

從哪裡得知此活動、報名原因（至少 2 項）、全程參與承諾。

系統會自動處理的事：

- 西元生日自動換算民國年，兩種格式都能輸入、都能搜尋。
- 年齡按「活動當天」計算並存下來，之後少年長大了，舊名冊上的年齡仍然正確。
- 身分證字號自動轉大寫去空白；電話全形自動轉半形。

## 把現有的 Google 表單回覆匯進來

從 Google 表單下載 CSV（回覆 → 下載回應 .csv），然後（記得先設 `DATABASE_URL`）：

```bash
# 建立新活動並匯入
node scripts/import-google-form.mjs 回應.csv --activity "向海出發~淨灘 x 獨木舟" --date 2026-08-14

# 匯入到已經存在的活動
node scripts/import-google-form.mjs 回應.csv --activity-id <活動 id 或代稱>

# 先試跑看看會不會有問題，不寫入任何資料
node scripts/import-google-form.mjs 回應.csv --activity "測試" --date 2026-08-14 --dry-run
```

- 身分證字號相同的人視為同一個人，會更新資料而不是重複建檔。
- 已經報名過同一個活動的人會自動略過，同一份檔案匯入兩次也不會重複。
- 資料不完整的那幾筆會被跳過並在畫面上列出是第幾行，其他人照常匯入。
- 新建立的活動預設是**關閉報名**的（避免舊活動被誤開放），
  要開放的話到後台編輯活動勾選「開放報名」。

## 資料存在哪裡

全部存在 Postgres 資料庫裡，共四張表：`activities`、`students`、
`registrations`、`login_attempts`。資料表會在第一次啟動時自動建立。

- 一個人只會有一筆 `students` 紀錄，用**身分證字號**當唯一鍵，
  所以同一個少年報名十次活動也不會重複建檔。
- 「同一個人不能重複報名同一個活動」是由資料庫的唯一索引把關的，
  就算兩個請求同時進來也擋得住。
- 報名時整段流程會鎖住該活動，**兩個少年同時按送出也不會超收名額**。
  （這在 Vercel 上特別重要，因為會有多個執行實例同時處理請求。）

**備份**：Neon 免費方案有時間點還原（PITR）。要自己留一份的話，
到後台的「學生資料總集」按下載 CSV，或用 `pg_dump` 匯出整個資料庫。

## 上線與安全

這套系統存的是未成年人的身分證字號、地址、監護人資料，屬於高敏感個資。
正式對外開放前請務必做到：

1. **一定要設 `ADMIN_PASSWORD`。** 預設的 `81599196` 是寫在
   `src/config.js` 裡的，而這個 repo 是公開的 —— 任何人看得到原始碼
   就等於知道後台密碼。密碼建議用長一點的英數混合，純數字 8 碼很容易被猜到。
2. **一定要設 `SESSION_SECRET`。** 沒設的話，登入權杖的簽章金鑰會從密碼推導，
   猜到密碼的人可以自己偽造登入權杖。用 `openssl rand -hex 32` 產一串貼上去即可。
3. **HTTPS**：Vercel 自動提供，自架的話要自己處理（Caddy、Nginx + Let's Encrypt、
   Cloudflare Tunnel 都可以）。沒有 HTTPS 的話報名內容和密碼都是明文傳輸。
4. 後台是**單一共用密碼**，沒有分帳號，所以看不出是哪位工作人員做的操作。
   如果需要追蹤誰刪了資料，要再擴充成多人帳號。

已經內建的防護：

- 後台所有 API 都要驗證登入權杖，密碼比對用定時安全比較。
- 後台密碼連續輸錯 10 次會鎖 15 分鐘（同一個 IP）。次數記在資料庫，
  所以 serverless 換執行實例也擋得住。
- 老朋友查詢要姓名、身分證、生日**三項全對**才會回傳資料，
  對一兩項不會透露任何訊息；同一個 IP 10 分鐘內最多查 30 次。
- CSP 只允許同源資源，沒有用任何外部 CDN。
- CSV 匯出會處理 Excel 公式注入（開頭是 `=` `+` `-` `@` 的欄位）。

## 專案結構

```
server.js                     本機／自架伺服器的進入點
api/[...path].js              Vercel serverless 進入點（處理 /api/*）
vercel.json                   Vercel 的網址對應與安全標頭
src/
  config.js                   設定（port、密碼、金鑰）
  fields.js                   報名欄位定義 —— 要改表單題目改這裡
  db.js                       Postgres 連線、資料表結構、交易鎖
  repo.js                     SQL 讀寫
  model.js                    活動／學生／報名的商業邏輯
  handler.js                  請求處理（本機與 Vercel 共用）
  api.js                      所有 API 路由
  auth.js                     後台登入與次數限制
  seed.js                     第一次啟動時的範例活動
  csv.js                      CSV 匯出
  http.js                     request/response 工具、靜態檔
  util.js                     民國年換算、身分證正規化等小工具
public/
  index.html / past.html      前台活動列表
  activity.html               單一活動報名頁
  admin/                      後台三個頁面
  assets/                     CSS 與前端 JS（原生模組，沒有打包步驟）
scripts/
  import-google-form.mjs      Google 表單 CSV 匯入工具
```

前端沒有打包步驟，改完存檔重整就生效。
